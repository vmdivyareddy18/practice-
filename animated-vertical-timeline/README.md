
# Animated Vertical Timeline

Small demo project using HTML, CSS and JavaScript to show an animated vertical timeline.

Usage:

- Open `index.html` in a browser (no build step required).
- The timeline items are rendered from `script.js` and will animate into view.
- The repo includes accessibility improvements and respects `prefers-reduced-motion`.

Files:

- `index.html` — demo page
- `style.css` — styles and animations
- `script.js` — sample data + rendering logic
