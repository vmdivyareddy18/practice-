# Mini Project 28: Color Mixer

A standalone HTML/CSS/JS color mixer that updates a preview and shows the current RGB value.

## Features

- Live color preview from RGB sliders
- Copy the current color string
- Reset to defaults

## Run

Open `index.html` in a browser.

## Usage

1. Drag the Red, Green, and Blue sliders.
2. See the preview update instantly.
3. Click Copy Color or press C.
4. Click Reset or press R to restore defaults.
